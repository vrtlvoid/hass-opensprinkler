1) Use Controller ID, Program Numbers and Station Numbers to derive unique HA Entity IDs
Avoid using Program Names or Station Names for entity IDs because the user can change the name at any time 
thus causing havock for Automations or Scripts that count on those names remaining contatnt.
Entities like "FY-P00-MWFS-S00toS06-1AM" Program Running become "OpenSprinkler FrontYard P00 Program Running"
where "OpenSprinkler FrontYard" is the unique Controller ID assigend when the HA OpenSprinkler
integration is created. This also avoids duplicate Entity IDs being created when there are mulitple OpenSprinkler
Controllers in a single HA instance and the user has identical Station Names like "Graden Sprinklers" applied
to more than 1 Controller.
